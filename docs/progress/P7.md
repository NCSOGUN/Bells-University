# P7: explanation engine (C09)

## Built
- `lib/explain/engine.ts`: `explainFact(fact, glossaryRow)` (pure, deterministic), `compareToPrintedRange`, `TEXT` (every fixed sentence), types `Explanation`, `GlossaryRow`.
- `lib/explain/lint.ts`: `findAdviceLanguage(text)`.
- `GET /api/facts/{id}/explanation` (holder only, labs only, 400 `not_explainable` otherwise).
- `tests/explain.test.ts` (29 tests): every status path, inclusive two-sided range, one-sided `< n` and `> n` at the boundary, no range, non-numeric, unreadable, unverified and check_carefully prefixes, missing glossary, g/L with a g/L range, an unusual printed range used as printed, no unit conversion, AI disclosure only for AI-read facts, and the NFR-19 lint over 50 facts covering every status and all 25 glossary rows. The lint is shown to catch bad text, and the module is checked to import no model or network code.

## Verified live
`GET /api/facts/{demo haemoglobin}/explanation` returns the design's example sentence verbatim; a medication returns 400. The JSON in docs/api.md is the real output.

## Decisions
- The unverified and check_carefully prefixes apply to every lab status, including unreadable.
- `because` and other words containing "caus" are avoided in templates (the lint matches the substring).
- Text from the document (label, value, unit, printed range) is quoted as printed. If a report prints a word like "Normal" inside its range column it would be quoted back; the lint covers our templates, not the document's own words.
