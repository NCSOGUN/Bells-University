## The rule, and how it is enforced
Reason and urgency come only from the referral's source fact (kind referral, state not unverified, not hidden from this viewer) and are copied verbatim. The create route rejects `reason`, `reason_as_written`, `urgency`, `urgency_as_written`, `urgency_code` with 400 `field_not_allowed`; `can(set_urgency_or_reason)` is denied for every actor (tested). The extraction guard also drops a referral field whose words are not in its own source quote (P2).

## Deviations
- Creating a referral uses the existing action `create_or_revoke_share` in `can()` (a patient act on their own record); no new matrix row.
- `acknowledge` has no database parameter, so a denied request never opens a connection.
- The packet's "documents" lists the documents behind included facts.
