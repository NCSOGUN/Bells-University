# P4: policy, identity, audit (C04, C12 writes)

## Built
- `lib/policy.ts`: `can(actor, action, resource) -> {allowed, reason, status}`; types `Actor`, `Action`, `Resource`, `Reason`, `Decision`; `ACTIONS`. Pure, lookup table per actor, default deny.
- `lib/auth.ts`: `getAccountId(request)` (Bearer header via service client `auth.getUser(jwt)`, else Supabase session cookie via `@supabase/ssr`), `getHolderActor(request)`, `requireHolder(request, recordId)`.
- `lib/records.ts`: `ensureAccount`, `createRecord`, `listRecordsForAccount`, `recordIdsForAccount`, `recordAiConsent`, `getAiConsentAt`, `hasAiConsent`.
- `lib/audit.ts`: `writeAccessLog(entry, db?)`, `writeFactEvent(entry, db?)` (insert only).
- `lib/http.ts`: `json`, `errorResponse`, `unauthenticated`, `notFound`, `forbidden`, `denied(decision)`, `parseBody(request, schema)`, `withErrors(handler)`, `RouteCtx`, `isUuid`.
- Routes: `GET/POST /api/records`, `GET/POST /api/consent`. Documented in `docs/api.md` with a Conventions section.

## Verified live (13 Nov 2026)
- No auth: `POST /api/records` returns 401 `{"error":{"code":"unauthenticated",...}}`.
- Demo user signed in through Supabase: `GET /api/records` returns the demo record; `GET /api/consent` returns null; an unknown body field gives 400; a forged token gives 401.
