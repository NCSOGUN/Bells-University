# P5: documents and extraction routes (C06 routes)

## Built
- `lib/facts/dto.ts`: `FactDTO`, `toFactDTO(row)`.
- `lib/storage.ts`: `DocumentStorage` interface, `supabaseStorage`, `storagePath()`.
- `lib/documents/service.ts`: `uploadDocument`, `getDocumentForRecord`, `listDocumentFacts`, `documentView`, `extractForDocument` (atomic claim L22, one retry on invalid model output, ONE transaction for facts + events + document update, referral-kind fact for referral letters per L21), with injected `Deps {db, storage, extract}`.
- Routes: `POST /api/documents`, `POST /api/documents/{id}/extract` (`maxDuration = 120`), `GET /api/documents/{id}`, `GET /api/documents/{id}/image`.
- `scripts/smoke.ts` (minimal, `npm run smoke`, `BASE_URL`, optional `SMOKE_FILE`).
- `docs/api.md`: FactDTO and the four routes.

## Verified live (13 Nov 2026, dev server, gemini-3.6-flash)
Smoke: 12/12 PASS. Upload 201, idempotent retry 200 with the same id, extract 200 with 3 facts all `ai_read`/`unverified`/`has_image`, second extract served from the database, image 302, unknown id 404. Model time 19.1 s on a one-page synthetic PDF (NFR-10 target 30 s; unthrottled).
