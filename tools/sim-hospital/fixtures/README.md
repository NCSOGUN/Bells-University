# SIMULATED hospital fixtures

Everything in this folder is SIMULATED and synthetic. "Demo General Hospital" is not a real hospital, the patient numbers (for example `DEMO-00123`) belong to no one, and every result, referral reason and clinician name was invented for testing Itan's partner feed. `{{LINK_REF}}` and `{{MRN}}` are placeholders the CLI fills in before sending. The bundles use the small FHIR R4-aligned subset Itan accepts (Bundle of type collection, one Patient, Observation and ServiceRequest only); they are not a claim of FHIR compliance.
